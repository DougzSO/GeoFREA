- **Migration of the recorded content hashes from `parquet:` to `parquet2:` (OQ-084).** The kinds coexist; an entry keeps its kind until it is restamped. A restamp is safe only for an entry whose byte hash `sha256` equals the file's today (the file is the one the hash described), as `scripts/stamp_manifest_hashes.py` does for missing hashes. Until then the 2 F5 tables written by pandas 3 with pyarrow 25 keep the `parquet:` hash of the official files and still show as changed; a new run that records them for the first time gets `parquet2:`.

The module is outside every closure anyway.
