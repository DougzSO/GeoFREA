## Data issues found while computing criterion 3 (2026-10-06)

- **CESM2 excluded: realization mismatch.** Its historical and scenario files carry different realizations, so a change
  factor would mix two ensemble members. Removed from the registry and the candidate set (marker entry
  `cmip6/cesm2/_realization_mismatch`).
- **AWI-CM-1-1-MR files held one year each (defect, fixed).** The CDS reply is a zip with one NetCDF per time chunk and
  the downloader kept only the first member, so the 12 files had 12 monthly steps (1995, 2041) while the registry claimed
  1995-2014 and 2041-2100; the validation read only the last time step. AWI's change factors were therefore invalid
  (for example IND dT -0.70 K). Fix (commit b383dc6): all members are merged and `check_temporal_coverage()` rejects any file
  without every month of the requested years. The 12 AWI files were deleted and downloaded again (all 2041-2100 or
  1995-2014, 185-250 MB each); the other 156 files were scanned and are complete. AWI now reads dT 1.84 K (BRA), 1.93 K
  (PRT), 1.04 K (IND).
- **Kernel bug found on the real crops (fixed).** `monthly_climatology` counted data values per year, so the NaN cells
  outside a country polygon looked like missing months and ACCESS-CM2 BRA failed the completeness check. It now counts the
  time steps. Regression test added.
