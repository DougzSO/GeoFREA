# LIMITATIONS.md: GeoFREA

Declared limitations of the method and every Tier 3 value. Each entry is written so it can be carried into the thesis limitations section.

Entry format: ID, statement, affected items, why it is accepted, where it is declared in the thesis (filled when written).

## Method limitations

| ID | Statement | Affects | Why accepted | Thesis section |
|---|---|---|---|---|
| L-001 | Solar potential assumes free-standing plants with c-Si modules at fixed optimum tilt (Global Solar Atlas PVOUT configuration); single-axis trackers are not modeled. | M-F5-02, T-R1, T-R2 | Only globally consistent PVOUT product available; trackers would require a separate irradiance model. | |
| L-002 | Climate change enters through annual-mean delta-change factors; seasonal redistribution of resource is not represented. | M-F4-03, M-F5-02, M-F5-03 | Atlas baselines are annual long-term averages; monthly baseline redistribution would require monthly atlas products and profiles. | |
| L-003 | Wind change factors from near-surface (10 m) `sfcWind` are applied at hub height, and Weibull shape `k` is held constant under climate change. | M-F5-03 | CMIP6 does not provide hub-height wind for the required ensemble; IPCC AR6 assigns low confidence to regional wind-speed trends, which is discussed alongside results. | |
| L-004 | Member CF ratios are evaluated at cell-mean Weibull parameters rather than per pixel. | M-F5-03 | Change factors are smooth at GCM resolution; the error is second order relative to cell-level resource heterogeneity. | |
| L-005 | Each GCM contributes a single realization; internal variability is not sampled. | M-F4-01 | Ensemble size is bounded by variable availability and computation; 30-year climatologies reduce internal-variability noise. | |
| L-006 | Climate of each window is held constant over the asset lifetime. | M-F6-01 | Annual trajectories add noise without changing results materially under discounting; two windows bracket the time dimension. | |
| L-007 | The 2071-2100 window extends beyond the lifetime of assets commissioned around 2030 and is interpreted as repowering or second-generation assets. | S-05, T-R6 | Needed to test H1 where SSPs diverge. | |
| L-008 | The reference climatology (1995-2014) does not coincide with the atlas reference periods (Global Solar Atlas: region-dependent start to 2024; Global Wind Atlas: see OQ-006). | M-F4-03 | Delta-change requires a common CMIP6 historical reference; 1995-2014 is the IPCC AR6 recent-past reference. | |
| L-009 | The transmission grid layer represents line location, not available connection capacity or voltage adequacy. | M-F2b-02, M-F6-01 | No consistent grid-capacity data exist for the three countries. | |
| L-010 | Exclusions E1 to E5 are shares of each pixel and E6 is binary; social acceptance and other non-monetizable siting factors enter only through exclusions. | M-F2b-01 | Keeps every output in physical units; the land-availability scenarios bound the effect (U-06). | |
| L-011 | Grid connection is costed per cell from eligible-area-weighted mean distance; shared connection infrastructure between neighboring cells is not modeled. | M-F6-01 | Cell decision unit (S-06); zones may be shown in F8 for presentation only. | |
| L-012 | Uncertain parameters are sampled independently; correlations (for example between CAPEX and discount rate) are not represented (verdict V5: independent sampling; no correlation without a sourced coefficient). | U-03, V5 | No defensible joint distributions for the three countries. | |
| L-013 | Results depend on the 0.05 degree aggregation (modifiable areal unit problem). | S-06, V-07 | Tested explicitly at 0.1 degree. | |
| L-014 | Extreme-wind context comes from ERA5 historical reanalysis and does not vary by SSP. | M-F1-05, M-F4-05, T-R10 | CMIP6 lacks consistent gust variables; low confidence in wind extremes trends. | |
| L-015 | Hazards without Tier 1-2 loss functions are reported as context and do not affect robustness metrics. | M-F4-05, H4 | Avoids driving results with unsourced values; exposure is still reported (T-R10). | |
| L-016 | External validation against existing plants measures plausibility, not accuracy, because plant locations reflect past auctions, policy, and grid access. | M-F7b-01 to M-F7b-04 | No ground truth for optimal siting exists. | |
| L-017 | The gust indicator (`fg10`, annual maximum, 1995-2014) is raw ERA5 reanalysis with no bias adjustment against station or other observed data. It is internally consistent for comparison across cells and years but is not an observed local gust value. | M-F1-05, M-F4-05, T-R10 | No bias-adjusted gust product exists at the required resolution/coverage across BRA, PRT, IND; CRAEI (which does bias-adjust its ISIMIP3b hazard channel, D-F4-001) has no gust product at all to adapt (D12). | |
| L-018 | The `grid` layer is OpenStreetMap power infrastructure of any voltage (lines and points), so distance to the grid is the distance to the nearest mapped feature, which can be a low-voltage line unable to absorb a utility-scale plant; the true connection point and the reinforcements it needs are not modeled. | M-F1-02, M-F2a-03, M-F3-03, M-F6-01 | No country-wide, voltage-resolved transmission dataset is available for BRA, PRT and IND; the effect is carried by the sampled grid-cost range (OQ-001). **Coverage measured 2026-10-06** (existing plants against the OSM layer, `docs/_audit/2026-10_plants_vs_osm_grid.md`): PRT complete (all plants within 14 km); BRA consistent (99.9% of capacity within 50 km; far distances are mostly real absence of grid); **IND incomplete** (24% of wind, 11% of solar, 41% of hydro units more than 50 km from a mapped feature; repeated 2026-10-07 with GEM, 5,727 IND units, same verdict as the 2020 GPPD list), so IND distances to the grid are overstated. | |
| L-019 | Connection CAPEX is linear in straight-line geodesic distance (`P x d x c`). Real costs also depend on voltage, line technology, capacity, terminal and reinforcement costs, losses and the actual route, and the cost-distance relation changes at long distances (HVDC vs HVAC), so the linear form is a first-order approximation, least reliable for remote cells. | M-F6-01, M-F2a-02, OQ-040, OQ-041 | Evidence supports distance entering cost continuously but gives no per-country voltage/technology/route data; the sampled `grid_cost_usd_per_mw_km` range (OQ-001) and the possible structural variant (OQ-041) carry the uncertainty. See `docs/_audit/2026-10_distance_connection_cost_evidence.md`. | |
| L-020 | The IND central candidate set rests on a Tier 3 population-density value (200 persons/km2, OQ-047). With the unsourced ranges (density, discharge, solar slope upper end) added, the candidate-set Jaccard of IND falls to about 0.67 (`docs/_audit/2026-10_systematic_review.md`, Appendix A.5). | M-F3-04, U-06, V1 | The sourced ranges alone leave the set stable (about 0.90); the unsourced ranges join the scenarios when OQ-047 is sourced. | |
| L-021 | Hazard exposure (T-R10 and the exposure half of H5) covers the nine members of the three GCMs with an ISIMIP3b counterpart (GFDL-ESM4, IPSL-CM6A-LR, MRI-ESM2-0) in the 2041-2070 window. The other three GCMs and the 2071-2100 window have no hazard rows (S-05, D-F4-004); they are reported as not available, never as zero, and no exposure statement is made for 2071-2100. | M-F4-05, M-F7-07 (H5), T-R10 | The 2071-2100 hazard data (about 183 GB) are not acquired before OQ-007 says that a hazard enters the LCOE (V8). | |
| L-022 | The scenario-discovery step uses a minimal own PRIM (peeling and pasting, real and categorical descriptors, one box). It reproduces `ema_workbench` 3.0.0 on five stored cases but differs in three documented ways: no integer descriptors (cast to real), categorical pastes are considered even when no real descriptor is restricted, and categories are visited in sorted order. The trajectory is written and the box is chosen by the pre-registered rule (the densest with coverage of at least 0.50 and at most three restricted descriptors, M-F7-08). The box describes the futures evaluated, not the space of possible futures; boxes are axis-aligned and describe poorly a vulnerability that depends on a ratio of variables; the climate descriptors are summaries over the shortlist and, with six climate models, a restricted GCM may reflect one model, not a physical condition. | M-F7-08 | `tests/fixtures/prim_reference.json` and `tests/unit/test_robustness_prim.py`; `scripts/generate_prim_reference.py` regenerates the fixture in a Python 3.12 environment outside `.venv`. | |
| L-023 | National expansion targets usually state the total installed capacity of a technology, including the plants already built, while the technical potential of GeoFREA does not remove the cells that existing plants occupy. The slack `H_0 = E_0 - G` of H5 is therefore a screening margin whose value depends on the source, the horizon and the unit conversion of the target. | M-F7-07 (H5), T-R12, OQ-010 | Removing existing plants from the potential needs plant locations and capacities that F7b uses only to validate plausibility (L-016); the source, the horizon and the original unit of each target are recorded with every result (`national_targets`), and alternative targets and conversions are sensitivities of H5. | |
| L-024 | The wind ensemble has five GCMs: the wind channel of MIROC6 is excluded in every country because its 1995-2014 mean 10 m wind over Brazil is below 0.5 m/s in 50.3% of its native land cells (minimum 0.001 m/s), against 0% in four of the other five GCMs and 18.8% in IPSL-CM6A-LR. The irradiance and temperature of MIROC6 are used, so solar has six GCMs. The other GCMs also have low 10 m winds over the Amazon, and the ratio of window to reference wind divides by them; the mask `wind_factor_valid_range` (no source, OQ-043) stays as a safeguard. | S-04, M-F4-02 item 6, M-F4-03, M-F4-07, T-R3, T-R6 | A reference field that is 0.11 of the Global Wind Atlas value (0.26 to 0.49 for the others) is not a basis for a ratio; excluding the channel acts on the cause, and the mask alone left 91,069 BRA cells that rest on a reference below 1 m/s (diagnostics report, section 2). | |
| L-025 | Wind candidates above 3000 m (`elevation_max_m` of `land_availability`, Tier 3, no source) are excluded from every land scenario, which affects India only (PRT and BRA have none; their highest wind candidates are 1356 m and 1922 m). In the F5 run that did not exclude them the cells were 1,316 of 62,718 central cells, 0.71 GW (0.37% of the capacity) and 1.11 TWh/yr (0.37% of the energy) in the central scenario; 8.3 GW in the permissive one. The limit has no source: a sourced criterion (IEC site conditions, turbine datasheets, density derating) is OQ-058, which stays open. | M-F2b-06, M-F3-04, M-F5-03, OQ-058 | A very high plateau is a siting question that a density correction does not settle; the cells are few, and the exclusion removes the cells whose air density is below 0.75 of the curve density from the central results. The density correction itself is applied at every altitude and is not truncated (group1_technical_potential subsec:g1_turbine). | |
| L-026 | `dT` is kept as the GCM gives it: three of the 36 members have cells with a negative `dT` over Brazil (6,264 cell-members, 0.06%), and the native cells of MRI-ESM2-0 that depart by more than 1 K from their neighbours are flagged (`dT_isolated_native_cell`) and counted, not corrected. The cause of the isolated cells is not diagnosed. | M-F4-03, M-F4-06, M-F5-02 | The effect on a solar cell is below 1% of its output per K of `dT`; a correction would be a rule with a free threshold. | |
| L-027 | The reference density of the IEA 3.4-130 power table (`rho0 = 1.225 kg/m3`, `verified = false`) is not read from the windIO or WISDEM inputs, which carry no air density; the table is a CCBlade output. The OpenFAST AeroDyn input (`AirDens`) and the HAWC2 master file of the same repository state give 1.225 kg/m3 for their own models. | M-F5-03 | `config/turbines/iea_3.4_130.csv` header; `docs/phases/F5/audit_groups1-2.md` section 3d; group1_technical_potential subsec:g1_turbine. | |
| L-028 | One class III turbine (3.37 MW, rotor about 130 m, specific power about 254 W/m2) is applied in every cell, rated below the machines installed in 2024; the design-class flag (reference mean speed of the 100 m layer above 7.5 m/s) reports the share of potential where a stronger turbine would be chosen but does not change it. Extreme wind, turbulence and tropical-cyclone exposure are not assessed. The 100 m layer represents the 110 m hub without a shear correction. | M-F5-03 | A single curve keeps the turbine identical across cells, countries and members; specific power, not rating, sets the shape of the curve and the density (group1_technical_potential subsec:g1_class, subsec:g1_limitations). | |
| L-029 | The residual land-utilization factor has no primary source in any country and dominates the spread of the potential in GW and TWh/yr; results for H5 and for the comparison with national targets are conditional on it. The three values are paired with the land scenarios and bound the joint effect of the mapped exclusions, the residual utilization and the density without identifying each. | M-F5-01, H5, U-06 | Author judgment; see L-204 and L-205 (group1_technical_potential subsec:g1_luf). | |
| L-030 | PV power density (45 / 50 / 75 MW_dc/km2) is transferred from United States plants of 2019 (Bolinger and Bolinger 2022; Ong et al. 2013) and is likely conservative for modules installed in 2024. Tracking systems are not modeled. | M-F5-01 | Tier 2 transfer with the international check of the source (group1_technical_potential subsec:g1_pd). | |
| L-031 | The PV yield is the fixed-tilt PVOUT baseline perturbed with annual means (`CF0 delta_rsds (1 + gamma dT)`), so changes in the timing of warming and the effect of wind and irradiance on the cell temperature are not represented; in the reference climate `gamma` has no effect. | M-F5-02 | The baseline already includes the thermal loss of the reference climate (group1_technical_potential subsec:g1_pv_thermal). | |
| L-032 | Wind air density uses one annual mean per cell and so ignores the covariance between density and wind speed; the density layer of the Global Wind Atlas (CFSR) and its wind field (ERA5) come from different reanalyses. The density of a member changes with the F4 warming at constant pressure, with `T* = 288.15 K` instead of the local annual mean (about 0.1 percent of the density ratio). | M-F5-03 | group1_technical_potential subsec:g1_turbine (air-density correction). | |
| L-033 | Inverter clipping and curtailment are not modeled; wind retention covers wake, availability, electrical and soiling losses only (`eta_loss`). | M-F5-02, M-F5-03 | group1_technical_potential subsec:g1_limitations. | |
| L-034 | RETIRED 2026-10-16: it described a 2026-vintage plant (t_ref = 2026). The vintage is now 2024 and the same limitation is L-042. | | The entry is kept so the ID is not reused. | |
| L-035 | RETIRED 2026-10-16: it described the transfer of the IRENA 2024 costs to a 2026 vintage. With t_ref = 2024 the costs and the vintage are the same cohort and there is no transfer in time. | | The entry is kept so the ID is not reused. | |
| L-036 | Portugal uses the European regional values of IRENA for CAPEX (a Tier 2 transfer of the same quantity and technology, not a proxy); the IRENA O&M table has no Portuguese wind row, so its fixed O&M is the midpoint and range of the European country rows (29 to 53 USD/kW/yr). | M-F6-07 | group2_core_costs subsec:g2_capex, subsec:g2_opex. | |
| L-037 | The upper tail of the capital-cost distribution beyond `2 mean - P5` is excluded, which removes the most expensive projects; this is consistent only if the connection costs of Group 3 represent what drives them. | M-F6-07 | group2_core_costs subsec:g2_capex, subsec:g2_limitations. | |
| L-038 | Fixed O&M is a fraction of the sampled capital cost, so absolute O&M scales with it; variable O&M is zero (the sources report all-in fixed O&M); IRENA does not state whether its O&M is per kW AC or DC, and the PV fraction is taken over the DC capital cost. | M-F6-01, M-F6-07 | group2_core_costs subsec:g2_opex. | |
| L-039 | The lifetime is a discrete uniform on the integers 25 to 30, each year with probability 1/6; the central value 30 is at the upper end, so the uncertainty is one-sided by design, and the central LCOE is lower than IRENA's for identical inputs because IRENA's standardized LCOE uses 25 years. | M-F6-02, M-F6-07 | group2_core_costs subsec:g2_lifetime. | |
| L-040 | The discount rate is the real after-tax regional WACC of IRENA 2024 (South America for Brazil, Asia for India, Europe for Portugal), with a range of plus or minus 1 percentage point that is author judgment (Tier 3). The Asian value (4.0% for PV and 3.8% for wind) is dominated by China and is likely low for India; it is consistent with IRENA's earlier country estimates once converted to real terms, but a higher Indian rate would raise every Indian LCOE. The rates reflect the financial conditions of 2023, are constant over the plant life, are regional averages and do not vary with project size or offtake contract. The country map of the report is unlabeled and its title and legend disagree on real or nominal; the real reading of the text is adopted. | M-F6-01, M-F6-07, OQ-054 | group2_core_costs subsec:g2_wacc. | |
| L-041 | The scope of the IRENA total installed cost with respect to grid connection is known only for PV and only on the plant side: the medium-voltage cables, switchgear, transformers, substation, meters and internal and access roads are in the cost breakdown (Table A2, p. 208), while a line to a distant transmission node is not stated. For onshore wind the report gives no scope sentence, so its connection scope is undefined. The distance-dependent connection cost of Group 3 may therefore count part of the cost twice for PV and cannot be placed against the IRENA cost for wind. | M-F6-01, OQ-001 | group2_core_costs subsec:g2_capex. | |
| L-042 | The plant is a 2024-vintage counterfactual (t_ref = 2024, the cohort of the IRENA 2024 costs) evaluated under the climate of every member, including mid-century and end-of-century windows; the same plant under every member keeps the climate effect separate from technology change. | M-F5-02, M-F5-03, M-F6-07 | group1_technical_potential subsec:g1_scope. | |
| L-043 | RETIRED 2026-10-16: it described the Tier 3 flag range of the Weibull layers (A in [1, 15], k in [1, 4]), replaced by the validity limits of L-211 (OQ-053 closed). | | The entry is kept so the ID is not reused. | |
| L-044 | A cell whose elevation is missing in the DEM (no eligible pixel has a value) is not a candidate, for wind and for solar, with the reason `missing_elevation` (`land_availability.missing_elevation: ineligible`); it keeps its eligible area in the cell tables. In the central scenario it removes 36 wind cells (35.7 km2) and 14 solar cells (4.5 km2) in India and 1 cell in Brazil (0.128 km2 for wind, 0.115 km2 for solar), none in Portugal: less than 0.01% of the eligible area. The rule is a decision of the author, not a physical statement about those cells. | M-F2b-06, M-F3-04 | The effect on the potential is below the precision of the inputs; the rule is explicit and counted in the F3 summary (`candidate_exclusions`). Before 2026-10-18 (METHODOLOGY 15.0.1) the rule was implicit: wind lost these cells through `elevation <= limit` and solar kept them (OQ-060). | |
| L-045 | RETIRED 2026-10-19 (COMMAND 55): it described 174,049 km2 of IND (the north block and Arunachal Pradesh) left out by the mask of the largest polygon; the contiguous mask of M-F2a-01 brings them in. The boundary question is now L-047. | | | |
| L-046 | RETIRED 2026-10-19 (COMMAND 55): it described the displaced elevation files of IND and BRA; the elevation is now built from GLO-30 (M-F2a-08, OQ-061 closed). | | | |
| L-047 | The country territory is GADM 4.1 level 0 as published, reduced to its contiguous part (M-F2a-01). Where a border is disputed the territory is whatever GADM draws as the country's polygons: for IND it includes the north block (the level-1 unit Jammu and Kashmir as GADM draws it, 73.77-79.30 E, 32.35-35.50 N, 102,792 km2 outside the earlier mask) and Arunachal Pradesh (65,388 km2); the code takes no position on any border and a different source (another version of GADM, Natural Earth, a national survey) would give another territory. Layers acquired per country are not extended over those blocks beyond what their source covers: the Global Wind Atlas files of IND, PAK and CHN together leave the two added blocks without wind (94.2% of the mask has a valid value after the completion of D-F1-030; the wind potential there is absent, not zero by physics), the OSM grid of IND has almost no feature there. | M-F2a-01, `docs/phases/core/geometry_dem_55.md` | The potential of the added blocks is reported apart in the F5 variation table. | |
